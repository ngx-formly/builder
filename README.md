# builder
A visual form builder for ngx-formly that brings community efforts together. Build Angular forms with drag-and-drop editing, custom components, live previews, and Formly JSON export.

## Development

Use Node.js 24.15 or newer within the Node.js 24 release line and npm 11.19.0.
The builder uses Angular 22 and Formly 11.
PrimeNG 21 and PrimeUIX themes 2 retain their MIT licenses; scoped npm overrides allow PrimeNG's Angular peers to resolve to Angular 22.

```sh
npm ci
npm start
```

Run `npm test`, `npm run lint`, `npm run check:docs`, and `npm run build` to validate changes.
